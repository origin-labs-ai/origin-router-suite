# v0.6.000 — 24 strategies, OriginFold, 142 providers

The strategy release. OriginRouter now runs **24 routing strategies**, folds
month-long conversations to a fraction of their tokens with **OriginFold**,
routes across **142 providers**, and — first time in the 0.6 line — can hold a
key back with **per-key budgets**. The suite (4,400+ tests) is wired into CI.

## Added

### 24 routing strategies

The router grew from 4 strategies to 24, all listed in one registry the
wizard, the combos editor and the engine dispatch share:

- **Rotation family** (from the OmniRoute school): strict-random deck draw,
  weighted, fill-first, power-of-two-choices, least-used, last-known-good.
- **Cost / context / cache family**: cost-optimized, context-optimized,
  cache-optimized, shadow-cache (prefix affinity + the encrypted shadow cache).
- **Quota family**: reset-aware, reset-window, headroom, quota-weighted,
  expiry-first — each consumes a pluggable quota-snapshot source and fails
  open to fairness rotation when there is none.
- **Adaptive family**: **Auto** (multi-factor self-healing scoring) and
  **AutoAgressive** — the situation adjusts the knobs, not the operator: the
  strategy classifies the turn and tightens the switch bar when seats degrade.
- **Latency Arbitrage**: real-time cost × speed × health arbitrage per seat;
  light tasks lean on price, heavy tasks on speed and health.
- **Pipeline**: seats run in sequence, each stage's draft feeds the next, and
  the final seat answers with the drafts attached. A lost stage still answers.

Every orderer fails open and returns a permutation — the fallback walk behind
it can still reach every seat. Legacy names normalize
(`priority`→fallback, `usage`→least-used, `cheapest`→cost-optimized,
`max_utility`→auto, `aggressive`→autoaggressive, `max`→smart).

### OriginFold — the conversation fold layer

The billion-context design, native. When a conversation crosses a fraction of
the model's context window, OriginFold folds consumed history into tiered
summary blocks and keeps a verbatim recent zone. The fold is append-only and
suffix-only, so the upstream prompt-cache prefix is never invalidated.
Reversibility instead of spillover:

- `compress_context` / `decompress_context` / `search_context` / `fold_status`
  are exposed as server-side tools for the MCP/A2A surfaces.
- Deterministic extractive summaries by default (model-free, safe).
- Every path fails open; conversations under ~20k tokens are never touched.

Division of labor with the rest of the token saver: RTK compresses tool
results in place, headroom compresses prompts at transport level (external
proxy), OriginFold folds the conversation itself.

### Hand Picked OpenAI Compatible

The user's own compatible endpoints get their own dashboard category, and
every provider without an icon asset — hand-picked endpoints, imports from
other routers, anything new — renders the letter glyph + deterministic accent
color (`NexAPI` → **N**, `OrcaRouter` → **OR**, `Orca-Router` → **OR**,
`Orca Route` → **OR**). Providers that have an icon keep using their icon.

### Mythos / Revolt Deffusion / Auto Agressive / Select-your-own

The wizard presets are renamed, spaced and extended to four. **Mythos** (formerly
"Max") is everything maxed: the merged Jev+Panda brain with the smart router on
top, compression ultra, every lane may run at once. **Revolt Deffusion** is the
same brain at medium/full compression. **Auto Agressive** is the new fourth
preset: the same merged brain on the AutoAgressive strategy — every turn is
classified, seats switch eagerly and the confidence bar tightens when a seat
degrades, the knobs the strategy moves itself. **Select your own** writes
nothing behind the user's back: strategy + brain + compression, khud decide
karo. The old `max` id keeps resolving as an alias so stored settings survive.

### Circuit breaker + seat health

Every seat outcome is recorded per combo. The orderers score health, cost and
latency from the same numbers the dashboard reports, and a seat that fails
three times in a row is demoted to the back of the order for a 60s cooldown —
demotion, never removal: the fallback walk can still reach every seat.

### CI test gate

The suite (4,700+ tests) runs on every push and PR. `npm test` is wired at the
root, the tests package has real scripts, and the global test timeout is
hardened against cold-cache flakes.

### The extension-pack architecture (Revolt Fusion)

The base stays featherlight; heavy categories hydrate on demand into
`<DATA_DIR>/fusion-modules/`, hash-verified against their manifest before a
byte lands on disk, hot-loaded with the `webpackIgnore` dynamic-import
pattern, and removable. Four Get Started tiers — **Daily Code** (zero extra),
**Pro** (hand-pick), **MHHRSM** (the full pack), **Ultra Ultimate Max**
(everything, every knob at its ceiling) — chosen in the wizard's new first
step and on the Fusion Setup page. The pack source is ours or a local
directory; no third-party repo is ever contacted.

### The deterministic surfaces

- **Provider Adapter Harness** — openai/anthropic/gemini adapters behind a
  `complete()` contract.
- **Reasoning state preservation** — captured `reasoning_content` replays
  where the same tool_call id reappears (LRU 200/2h, ≤20 blocks); strict
  thinking-mode upstreams stop rejecting follow-up turns.
- **MCP server** — JSON-RPC 2.0 at `/api/mcp` with six router tools.
- **A2A protocol** — Agent Card at `/.well-known/agent.json`, bounded task
  lifecycle at `/a2a`.
- **Mid-stream recovery** — a delivered-prefix snapshot lets a dead stream
  continue on the next seat instead of repeating.

### Compression engines + gates

A plugin registry ordered by stack priority; the lossless pair ships
built-in behind a fidelity gate, a risk gate that shields credential-shaped
spans, and per-model exclusions. Lossy engines arrive via the pack only
after their eval harnesses pass.

### Local Models

A new dashboard page: live Ollama / LM Studio / llama.cpp engine probes,
unified Hugging Face + Ollama-library search, one-click pull/download with
progress and cancel (argv-array spawns, never shell), and "+ Add model file"
registration for existing .gguf/.safetensors/.bin files.

### Migration sources

Five sources now: other router installs, OmniRoute, Free Claude Code,
**9Router** (full connection/combo/settings import through the shared SQLite
dialect), and **OpenCode CLI** (provider definitions with api keys from its
opencode.json — registry-mapped or as compatible nodes).

### Memory Fabric + Shadow Cache

An opt-in persistent shared context layer (remember/recall/forget with
scope keys), and an encrypted local response cache for temperature=0
requests — AES-256-GCM, LRU-backed, bypassable per request.

### Cloud Sync (Google Drive, the one option)

Sign in with Google in the wizard's Cloud sync step; backups land in Drive's
appDataFolder with credentials REDACTED (keys never leave the machine),
restore merges non-credential parts back. Status, sync-now and restore live
on the API + wizard step.

### Settings resets

Profile page's Danger zone: **Restore default Claude Code config**
(backup-restore or surgical key removal — unrelated settings never touched)
and **Reset OriginRouter** (scoped factory reset, backup taken first, API
keys always survive, `RESET` typed to confirm).

### Skills pipeline

Import the code-fusion payloads catalog (952 skills) with the CONFLICT.md
merge policy: existing wins, internal duplicates first-by-name wins,
conflicts recorded with both sides. Skills are data — hashed and copied,
never executed. One-click scan → review → install on the Skills page.

### The provider graveyard

[docs/PROVIDER-GRAVEYARD.md](docs/PROVIDER-GRAVEYARD.md) documents, per
provider in the reference catalogs, the actual status: shut down (with
dates), deprecated in our own registry, web-cookie-only, special-auth, or
unverified. Dead providers are excluded and the exclusions travel with the
id.

### DB manager

The Fusion Setup page shows every table categorized (core / features /
analytics) with row counts, and the three data-retention presets (minimal /
standard / full) plus prune and vacuum — the sane answer to a 223-migration
schema museum.

Step 1 of 3

Choose where OriginRouter saves data

This folder holds db/data.sqlite, request logs, token caches and — once you add keys — plaintext provider credentials. Pick somewhere private and backed up.

folder_open

The browser folder picker cannot reveal the full path, so confirm or type it above. Default is ~/.or. A path in DATA_DIR overrides everything.

check_circle

Folder handle acquired. Files can be written here directly.

Protect this folder. Provider API keys are stored in the local database as plain JSON. Use an OS account with a password and avoid shared or synced folders such as a public Dropbox directory.
